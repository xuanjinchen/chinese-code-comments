# Security Policy

## Supported Versions

Only the latest GitHub Release is supported with security fixes. The `main` branch is a development version and is not a stable support target.

## Reporting A Vulnerability

Use **Security > Report a vulnerability** in this repository to submit a private vulnerability report. Do not open a public Issue for a suspected vulnerability, and do not include credentials, tokens, private source code, or personal data in public discussions.

Include the affected version, installation method, impacted Agent, reproduction steps, security impact, and any suggested mitigation. The maintainer will coordinate validation, remediation, and disclosure through the private report.

Public reports that do not contain sensitive details may use the normal Issue template.
